# Senorita Android App

A ready-to-open Android Studio project for the Senorita food/catering app.

## Included
- Senorita branding and mobile-first UI
- Mobile login + demo OTP (1234)
- Home, Menu, Custom Box, Cart, Profile
- Local cart persistence
- WebView wrapper so the supplied UI runs inside a real Android app

## Build APK
Open this folder in Android Studio, let Gradle sync, then choose:
Build > Build Bundle(s) / APK(s) > Build APK(s)

The official Android build flow uses Android Studio/Gradle and the Android SDK to compile the APK.

## Demo login
Any 10+ digit mobile number + OTP `1234`.
